% Deployment view (C4): where ETHOS.Data runs and where its data lives.
%
% Three bands. Top: the machines outside the cluster (a package's CI runner,
% a workstation, ETHOS.Data's own CI runner, an optional maintainer
% workstation). Middle: the hosts every band talks to (dCache, GitHub,
% Keycloak, JuGit). Bottom: the ICE-2 cluster computer, with the users'
% environments on the left, the shared storage in the middle and the
% maintainer environment on the right, so users' reads come in from the left
% and maintainers' writes from the right without crossing.
%
% The hosts are ordered so that no arrow crosses another: dCache is under the
% users and the package CI, JuGit under the maintainers. The cluster's arrows
% to hosts further left run lower in the channel, so they nest; the users'
% download jogs left under them, past the cluster's label. Arrows into a host
% enter right of its label. Coordinates are millimetres; the picture is 162
% wide.
